# Quickstart: WebUI Terminal Login

1. Start local CubeSandbox and WebUI.
2. Create or resume a sandbox so it is running.
3. Open WebUI sandbox list or detail page.
4. Click "Open terminal".
5. Run `ls`, `top`, and `ping -c 1 127.0.0.1`.
6. Resize the terminal panel and verify output adapts.
7. Close the terminal and verify the session closes with an audit log.
