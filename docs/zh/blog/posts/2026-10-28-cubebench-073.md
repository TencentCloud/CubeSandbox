# CubeSandbox 核心操作性能基准测试报告（CubeBench v0.7.3）

> 生成时间：2026-10-28 18:28:58

## 1 概述

本报告从以下维度对 CubeSandbox 进行基准测试：

- **3.2 冷启动延迟与并发扩展**：以不同并发度批量创建沙箱时的创建延迟、单个成功创建沙箱的 wall time 及吞吐量。
- **3.3 单机部署密度（内存开销）**：分批启动沙箱，以测量单机容量和单实例内存开销。
- **4.1 Snapshot 制作耗时与并发的关系**：并发度提升时的 Snapshot 制作耗时。
- **4.2 Snapshot 制作耗时与 Dirty Page 大小的关系**：Dirty Page 大小增加时的 Snapshot 制作耗时。
- **4.3 基于 Snapshot 创建沙箱**：基于 Snapshot 启动沙箱所需的时间。
- **4.4 Rollback**：回滚至 Snapshot 所需的时间。
- **4.5 Clone**：克隆沙箱所需的时间。
- **4.6 Pause / Resume**：暂停和恢复沙箱所需的时间。
