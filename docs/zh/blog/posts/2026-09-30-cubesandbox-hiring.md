# 全球招聘｜给全世界的 AI Agent 造底座，缺一个你

五个月前，我们把 CubeSandbox 开源了。

今天，它的脚印已经落在世界各地——中国、日本、印度、伊朗、加拿大、墨西哥、意大利、新加坡…… 12,000+ 颗 Star，来自不同时区的开发者。

但我们觉得，这只是开始。

AI Agent 时代正在到来。每一个 Agent 写出的代码、执行的命令、打开的文件，都需要一个安全的地方运行。

这就是沙箱的使命：为全世界的 AI Agent，打造更快、更稳、更高效的底座运行环境。

**CubeSandbox 要做的，是把这样的沙箱提供给全世界——用更快、更好、更稳的产品与技术，辐射到更多的国家和地区。**

这件事很大，所以，我们想找一个一起造它、一起筑梦的人。

## 岗位详情

**腾讯云 - CubeSandbox 弹性计算平台研发工程师（深圳）**

- **BG**：CSIG 云与智慧产业事业群
- **职位类别**：技术 / 技术研发类
- **工作地点**：深圳

**岗位职责：**

1. 负责 CubeSandbox 弹性计算平台全链路的需求研发和性能、质量保证，包括但不限于管控面、调度、虚拟化、存储、网络、底层系统软件等；
2. 支撑腾讯云 CubeSandbox 内部的业务需求及外部开源社区的日常研发维护；
3. 持续基于 CubeSandbox 平台探索 Agent 对 Infra 的新需求。

**岗位要求：**

1. 计算机相关专业，本科及以上学历，3 年以上相关工作经验；
2. 扎实的系统编程能力（Rust / Go / Python），对代码和架构有简洁易维护的良好审美；
3. 热衷于探索系统运行的基本原理，对于新鲜技术有着浓烈的好奇心并可以长期持续跟踪；
4. 对于计算机体系结构 / 网络 / 存储 / 虚拟化 / 调度其中某一方面有大规模的实际项目经验，或对于性能有极致追求；
5. 良好的团队协作和问题攻坚能力。

投递简历，或者如果对岗位有疑问，请发送邮件到 **cubesandbox@tencent.com**。

也欢迎转发给你想到的任何一个人。

从深圳到东京，从多伦多到米兰——好的基础设施没有国界。

我们希望有一天，世界各地的每一个 Agent，都跑在我们造的底座上。

来，加入我们，一起把这件事做成。
