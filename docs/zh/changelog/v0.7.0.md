CubeSandbox 0.7.0 引入了4个核心特性以及多个功能增强与问题修复。共计 239 个提交，来自 57 位贡献者。

### 🎯 核心特性

#### 跨机暂停恢复

基于S3后端存储支持跨机的pause/resume以及基于snapshot创建沙箱，该功能目前是预览版本。

#### 组件多版本

- 新建的模板、快照会包含所依赖的组件版本信息，后续在计算节点组件升级后，历史的模板、快照仍然可以使用，升级也不再影响已有实例的pause、resume，存量业务稳定性更有保障。

#### 网络子系统重构，加速沙箱网络创建流程

- 架构优化：减少组件部署，将 network-agent 组件合并进 Cubelet，减少沙箱创建流程中的进程间 RPC 调用；重构 TAP 设备生命周期管理，避免网络规则跨沙箱泄露，减少边界风险
- 性能优化：优化 eBPF 网络策略下发路径，大幅降低带有网络规则的沙箱创建延迟；减少不必要的 netlink dump 操作，当空闲 TAP 设备耗尽后，保障高并发创建新 TAP 设备的稳定性

#### 控制面/运维架构分离

在架构上，将运维能力从CubeMaster中分离。把节点管理逻辑独立到CubeOps中，支持多副本部署，提供cubeopscli工具。

### ✨ 功能增强

#### 模板与存储

- CubeS3lvol COW (#1490): cubecow在原本的本地XFS cow引擎之外，新增支持基于对象存储S3的远程快照存储，支持跨节点的暂停恢复和快照克隆。
- 私有 HTTP 镜像仓库支持(#1369)：支持从http镜像仓库拉镜像来做模板
- 内置 MinIO 作为默认 S3 卷后端(#1408)：默认部署minio作为s3后端，用于volume功能、跨机暂停恢复。同时，用户也可自行指定s3后端。

#### 生命周期与控制面

- 新增节点删除功能（#1202）：支持从集群中删除节点，使其不再参与调度。

#### 网络与安全代理

- 网络子系统重构，将 NetworkAgent 整体嵌入 Cubelet，优化网络创建流程
- 支持运行中的沙箱动态更新网络策略
- CubeEgress 七层转发规则支持自定义端口
- CubeVS 同子网 MAC 地址学习，避免非 hairpin 网络通信黑洞
- CubeProxy 支持自定义管理端口，支持 gRPC 协议

#### SDK

- Volume 能力补齐：Go（#1269）与 Node（#1277）SDK 新增 Volume CRUD 与 `volumeMounts` 挂载，三语言能力拉齐。
- 模板别名完整支持：构建时别名（#1119）与现有模板别名管理（#1120），覆盖 Go / Node / Python。
- Go SDK 用户级文件视图（#1348）：`Files.ForUser` 按用户身份隔离文件访问。
- Node SDK 运行时 timeout（#1251）：`Sandbox.setTimeout(timeout)` 支持 `NEVER_TIMEOUT`。
- Python SDK 沙箱调度范围（#1144）：`Sandbox.create(distribution_scope=...)` 显式指定沙箱可放置的节点/区域。
- Go SDK 私有沙箱数据面修复（#1185）：RunCode / Commands / Files / PTY 正确透传 TrafficAccessToken。
- Node SDK 认证头修复（#1360）：调用方显式传入的 `Authorization`（含小写形式）不再被 SDK 默认 `apiKey` 覆盖。
- 三语言 SDK clone 快照延迟清理（#1095）：引用计数，所有 clone 销毁后才删除临时快照。

#### 部署与运行时

- 日志轮转策略可配置(#1339)：用户可通过配置文件调整cubelet的日志轮转策略。
- 内核 / guest 镜像产物独立发布(#1324): 版本发布不再重新编译内核和 guest 镜像,而是从专用的 `kernel-release-*` / `guest-image-*` Release 拉取固定版本

#### Web UI / CubeOps / 其他

- CubeOps：节点管理能力移至本模块；新增cubeopscli工具管理节点功能并移除cubemastercli node子工具；默认支持双副本部署；（#1384、#1494）
- Web UI：提供节点隔离/解除隔离功能；提供查看节点操作记录功能；（#1384）

### 🐛 Bug 修复

#### 生命周期与沙箱

- 修复暂停/恢复失败引发的沙箱状态不一致、僵尸进程及删除异常等问题（#978，#985，#1137，#1274）
- 修复快照性能问题（#1300，#1504）
- 修复并发创建沙箱时的模板缓存数据竞争(#1366)

#### 网络与安全

- 修复暂停/恢复及节点重启场景下，TAP 设备恢复异常导致沙箱状态异常等问题（#930，#987，#1207）

#### 其他

- 修复日志轮转配置失效（#1289）
- 扩展 Python SDK 兼容性端到端测试，新增文件系统、回滚与克隆、在线超时更新、异常生命周期及高级模板参数等场景的覆盖（#1226）
