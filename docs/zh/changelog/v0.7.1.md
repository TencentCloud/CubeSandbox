## 2026.09.11 Release v0.7.1

CubeSandbox 0.7.1 引入了 1 个核心特性以及多个功能增强与问题修复。共计 70 个提交，来自 24 位贡献者。

### 🎯 核心特性

#### Cube 控制面服务支持全链路高可用

- 独立模板中心服务，使得 CubeMaster 可多副本部署。
- 生命周期管理服务支持主备模式部署。

### ✨ 功能增强

#### 模板与存储

- Snapshot 支持 Host Mount 与 Volume Plugin：支持对包含外部挂载的沙箱执行快照、恢复、回滚和克隆（#1654，#1656）。
- 独立模板中心 CubeTemplateCenter：模板构建 / 删除 / 回收从 CubeMaster 拆分为独立可多副本部署，构建产物持久化到 S3/MinIO（兼容 AWS S3），并修复并发构建竞态、artifact 表名不一致与本地盘存储易失等长期问题（#1659）。
- 跨机快照同桶恢复提速（#1663）：从同一桶恢复快照改走对象存储服务端拷贝，速度显著提升；同时完善延迟删除的回收，新增快照取消能力。

#### 生命周期与控制面

- CLM 支持主备容灾。
- 运行中的沙箱不再阻止快照删除（#1620）：删除仍被引用的快照立即生效，底层存储在最后一个引用释放后自动回收。

#### 安全

- virtiofsd 安全加固（#1612）：设置目录白名单后拒绝针对根目录的变更操作，并拒绝伪造的 readdirplus 请求。

#### 部署与运行时

- K8s 支持部署 CubeS3lvol（#1637）：可在 K8s 上使用 S3 后端的跨节点暂停恢复与快照。
- 一键部署支持外部 PostgreSQL（#1644）：通过 `CUBE_DATABASE_DRIVER` 选择 MySQL / PostgreSQL，接入自建数据库实例。
- CubeS3lvol 改为显式开启（#1622、#1633）：需设置 `[cow.s3] enable = true`（一键部署用 `ONE_CLICK_ENABLE_S3LVOL=1`），默认关闭；同时修复一键部署升级时该开关不生效的问题。升级注意：此前未显式配置但实际在使用 S3 的节点，升级后需显式开启。
- Helm 统一 Redis 逻辑库配置（#1638）：新增顶层 `redis.db`，统一作用于 CubeMaster / CubeProxy / CLM；多套集群共享同一 Redis 时可按集群隔离逻辑库。

#### Web UI / CubeOps / 其他

- cubemastercli 批量删除模板（#1549）：`tpl delete` 支持一次传入多个模板 ID。

### 🐛 Bug 修复

#### 生命周期与沙箱

- 修复沙箱设置为永不过期（`NEVER_TIMEOUT`）后被立即判定为已过期的问题（#1401）。
- 修复创建请求中非法的 CPU / 内存规格被按 0 处理，导致沙箱绕过节点资源过滤、可被调度到任意节点的问题（#1463）。
- 修复恢复（Resume）时传入的新超时时间被丢弃、沙箱仍沿用暂停前超时的问题（#862）。
- 修复 S3 后端恢复后再创建快照退化为全量内存导出的问题，快照保持增量（#1688）。
- 修复基于模板创建的沙箱无法查看日志（`cubecli logs` 无输出）的问题（#1616）。
- 修复计算节点无响应时模板创建可能无限卡住的问题，增加超时控制（默认 300 秒，可配置）（#994）。
- 修复节点下线 / 删除后对应 gRPC 连接未及时关闭的问题（#1585）。
- 修复新版 s3fs（1.97+ / FUSE3）下 S3 卷挂载失败的问题（#1647）。

#### 网络与安全

- 修复经透明代理访问 LLM 等慢首包上游时，超过 60 秒即被 504 断开的问题；代理收发超时提升至 2 小时（#1655）。
- 修复网络规则注入过大的凭据值导致 CubeEgress 异常的问题；单条注入上限与 E2B 对齐为 2048 字节（#1606）。
- 修复 TAP 设备名超过内核长度限制被静默截断，导致网络设备查找失败的问题（#1552）。
- 修复节点启动初期网关 ARP 缓存未就绪导致 Cubelet 网络插件初始化偶发失败的问题（K8s 部署下）（#1609）。
- 镜像仓库访问凭据不再出现在组件日志中（#1600）。

#### 部署与升级

- 修复 Helm 升级时 Redis StatefulSet 因 PVC 标签变化而失败的问题（#1604）。
- 修复 `global.imageRegistry` 误改写显式指定的私有 / 第三方镜像仓库地址的问题（#1605）。
- 修复 helm test 测试 Pod 在带 taint 节点上一直 Pending 的问题（#1388）。
- 修复 Terraform 部署时节点查询失败（健康节点数为 0）导致校验与模板创建被跳过的问题（#1602）。
- 修复 CubeOps 使用独立 Redis 配置时逻辑库编号不生效，导致节点指标不可见、调度指标更新超时的问题（#1607）。
- 修复日志级别配置为小写（如 `info`）时不生效、回落到 DEBUG 的问题（#1597）。
- 修复 Ubuntu 20.04 上构建 builder 镜像失败的问题（#1588）。

#### 其他

- Node / Python SDK：修复命令执行传入 `0` 或 `NEVER_TIMEOUT` 超时后请求永不返回的问题（#1485）。
- 修复 cubeopscli 版本号显示错误（硬编码 0.1.0）及 `version` 子命令不可用的问题（#1596）。
- 修复 cubemastercli `version` 命令默认无输出的问题（#1657）。
- 修复 Web UI 运行配置页展示已废弃配置项的问题（#1573）。
