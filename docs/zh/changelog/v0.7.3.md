## 2026.10.12 Release v0.7.3

32 个提交，来自 15 位贡献者。

### ⭐ 亮点

- **修复访问沙箱偶发网络不通问题** 提升网络稳定性。
- **优化S3lvol组件缓存机制** 提升跨机恢复性能。
- **优化S3lvol 组件热升级：提升组件升级时的I/O 恢复时间**。

### 🎯 核心特性

#### 沙箱支持 MCP（E2B兼容）

创建沙箱时支持传入与 E2B 兼容的 `mcp` 参数，在沙箱内启动 MCP（Model Context Protocol）网关：

- Python / Node / Go SDK 均已支持，可直接获取 MCP 连接地址和 Token
- 网关可替换为任意符合约定的自定义实现，cube 在 `examples/mcp-gateway` 提供了默认参考实现

### ✨ 功能增强

#### 模板与存储

- S3lvol 热升级：升级期间沙箱 I/O 的暂停时间大幅缩小，从约 40 秒缩短到约 8 秒（#1822）。
- 跨机恢复无需把整块磁盘拷到节点，恢复出的沙箱按需进行懒加载，重复数据可以利用本地缓存加速（#1898）。
- 优化模板创建时的节点有效性检查，当发现问题时提前报错，提升模板创建体验（#1829）。

#### 生命周期与控制面

- 实例暂停实现优化：优化实例暂停提层实现，单次暂停速度提升约 41%（2 GiB 沙箱 150ms → 88ms），并发 50 时速度提升约 20%（#1731）。

#### 部署与运行时

- PVM host / guest 内核从 6.6.69 升级到 6.6.117（#1852）。

#### Web UI / CubeOps / 其他

- Web UI 模板卡片支持展示模板别名（#1876）。

### 🐛 Bug 修复

#### 生命周期与沙箱

- 修复暂停后的沙箱在 Info 查询中丢失元数据（labels、模板、规格、卷挂载）的问题（v0.7.0 引入）（#1861）。
- 修复偶发的克隆报 `no more resource` 的问题（#1909）。
- 修复集群中模板较多时模板列表请求挂起的问题（#1899）；列表接口与 `cubemastercli tpl ls` 同时支持分页（`limit` / `offset`）。
- 修复删除沙箱时偶发的资源回收问题（#1810）。
- 修复块 I/O 偶发的数据被截断或卡死的问题（#1825）。
- 修复从快照创建沙箱时，客户端重发相同的 volumeMounts 被拒绝（"must have exactly one declaration"）的问题（#1894）。

#### 网络与安全

- 修复访问沙箱连接五元组冲突问题，导致网络偶发不通的问题（#1915）。
- 优化会话回收逻辑，提升回收效率（#1914）。
- 修复沙箱网卡重用导致的连接被重置的问题（#1919）。
- 修复会话状态未刷新问题（#1918）。

#### 部署与升级

- 优化 cgroup v2 相关错误日志（#1869）。
- 修复 `cubemastercli` 僵尸进程不断堆积的问题，存量部署重启一次 Pod 即可清理（#1860）。

#### 其他

- 修复从已删除的快照创建沙箱返回 HTTP 500、SDK 无限重试的问题（#1868）。
- 修复 Go SDK `Watcher` 并发场景下重复关闭问题（#1405）。
