## Unreleased Release v0.7.4

### 🎯 Major Features

#### Sandbox-to-sandbox access and exposed-port endpoints

Sandboxes can reach services in other sandboxes through the hostIP:hostPort
endpoint of a template-declared exposed port. The Python / Node / Go SDKs
expose `get_exposed_port_endpoint` / `GetExposedPortEndpoint` /
`getExposedPortEndpoint`, returning a ready-to-dial `hostIP:hostPort` string.

- The endpoint form is uniform for off-node, host-side, and in-sandbox
  callers; no caller-address based mode selection is involved.
- Same-node sandbox-to-sandbox access is delivered by CubeVS hairpin:
  from_cube SNATs the packet and loops it back into the primary NIC ingress,
  where from_world applies the port-mapping DNAT — no NIC/switch hairpinning
  is required.

**Node version requirement**: same-node sandbox-to-sandbox access requires a
hairpin-capable CubeVS (shipped in the same release as this API). Older nodes
have no same-node access at all (neither hostPort nor tap-direct); upgrade the
nodes to gain it — no caller-side changes needed.
