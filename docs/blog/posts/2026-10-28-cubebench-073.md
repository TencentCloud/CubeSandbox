# CubeSandbox Core Operations Performance Benchmark Report (CubeBench v0.7.3)

> Generated at: 2026-10-28 18:28:58

## 1 Overview

This report benchmarks CubeSandbox across the following dimensions:

- **3.2 Cold-Start Latency and Concurrency Scaling**: creation latency, wall time per successful sandbox and throughput when creating sandboxes in batches at different concurrency levels.
- **3.3 Single-Host Deployment Density (Memory Overhead)**: launch sandboxes in batches to measure single-host capacity and per-instance memory overhead.
- **4.1 Snapshot Creation vs Concurrency**: snapshot creation time as concurrency grows.
- **4.2 Snapshot Creation vs Dirty Page Size**: snapshot creation time as the dirty page size grows.
- **4.3 Create Sandbox from Snapshot**: time to start sandboxes from a Snapshot.
- **4.4 Rollback**: time to roll back to a Snapshot.
- **4.5 Clone**: time to clone a sandbox.
- **4.6 Pause / Resume**: time to pause and resume a sandbox.
